# Editing technique contracts

17 generic contracts in [catalog.json](catalog.json), derived from the [art-direction study](../../../research/art-direction/ART_DIRECTION_STUDY.md). They describe narrative choices, assets, hierarchy, advisory text budgets, motion and relation-based transitions. They are not 17 effect wrappers and do not define a channel identity.

| Technique | Narrative problem |
|---|---|
| `archiveHero` | Gerçek bir nesneyi, olayı veya materyali ilk bakışta kurmak. |
| `archiveDetailFocus` | İzleyicinin gerçek materyalde hangi ayrıntıya bakacağını seçmek. |
| `documentHighlight` | Bir iddiayı gerçek belge/ürün üzerindeki belirli kanıtla bağlamak. |
| `mixedMediaCollage` | Farklı kanıt materyallerini tek anlamlı kompozisyonda ilişkilendirmek. |
| `splitContrast` | İki nesne veya durumun gerçek karşıtlığını bir bakışta açıklamak. |
| `visualEquation` | Sebep/sonuç veya dönüşüm ilişkisini gereksiz flowchart olmadan göstermek. |
| `mapRoute` | Yer, rota veya yolculuk çabasının farkını açıklamak. |
| `photoToDiagram` | Gerçek durumun görünmeyen ilişkisini açıklayıcı grafiğe geçirmek. |
| `documentToTimeline` | Belgedeki gerçek bilgiyi kronolojik ilişkiye dönüştürmek. |
| `headlineReplacement` | Kısa ifadedeki anlam değişimini tipografik olarak belirginleştirmek. |
| `numberImpact` | Ölçülen büyüklüğü veya tarihi doğru anda ana bilgi yapmak. |
| `sharedObjectTransition` | Bağlantılı sahneler arasında aynı nesneyi algısal köprü yapmak. |
| `maskMatchCut` | İlişkili iki görseli ortak şekil/kenar üzerinden bağlamak. |
| `editorialPush` | Yeni materyali mevcut mekânsal bağlam içinden devralmak. |
| `foregroundReveal` | Ön plan nesnesiyle ilgili arka materyali açıklamak. |
| `photoStack` | Bir seri materyali, koleksiyon veya kanıt dizisi olarak karşılaştırmak. |
| `dataOverlay` | Gerçek konu görüntüsü üstünde ölçülen ilişkiyi açıklamak. |

`mapFocus` is a documented alias of `archiveDetailFocus` with a map asset, not an eighteenth technique. Each scene must record which contracts it actually uses; listing every contract is not validation.
