# Gerçek ses kaydı

İnsan tarafından kaydedilen orijinal sesi `voice_original.wav` olarak buraya koyun. Bootstrap bu dosyayı üretmez. Orijinali koruyun; normalize edilmiş ses veya yeni kurgu türevlerini farklı dosyalara yazın.

Tekrar okuma istekleri `pickups/pickups.json` içindedir. `start` ve `end`, orijinal kayıt saatine göre saniyedir. Yeniden okunan dosyaları `pickups/` altında tutun; v0.1 otomatik splice yapmaz.
